# 最小基因调控回路：可复现 LaTeX 学习笔记

这是一个偏理论物理取向的中文入门项目，范围限定于最小化学反应、单基因反馈、双基因回路、三组分反馈/前馈、随机出生-死亡过程，以及到真实 GRN 的三个桥梁；当前版完整枚举 81 种带标签的两节点符号拓扑，并结合 Ma 等与汤超的 Cell (2009) 论文展开三节点适应讨论。它是可编辑学习笔记，不是所有两节点化学反应机制的数学穷举。

## 文件清单
- `main.tex`：中文 LaTeX 完整源码，含连贯的模型讲解与完整推导、TikZ 调控关系图、案例和参考文献。
- `main.pdf`：已经编译完成的 PDF。
- `code/make_figures.py`：原有五张数值图的可复现绘制脚本。
- `code/topology_analysis.py`：穷举 81 种两节点拓扑，生成八组索引图和逐图 LaTeX 图谱。
- `code/topology_inventory.json`：每张图的边符号、编号和结构分组。
- `code/positive_feedback_oscillation.py`：R8 快慢回路的迟滞几何、调频与振幅演示。
- `code/extended_examples.py`：两变量恢复/振荡、缓冲/比例/泄漏适应的机制演示与数值检查。
- `figures/*.pdf`：矢量插图，LaTeX 直接引用。
- `figures/*.png`：方便预览的对应位图。
- `requirements.txt`：绘图依赖。
- `build.sh`：重新生成图并用 XeLaTeX 编译三遍。

## 使用方法
```bash
python -m pip install -r requirements.txt
bash build.sh
```
也可只重新编译 `xelatex -interaction=nonstopmode main.tex` 三遍。

需要 XeLaTeX、ctex 和 TikZ 宏包；中文字体使用 TeX Live 自带的 Fandol，避免依赖 macOS 专有字体。脚本以自身位置定位插图输出，支持从项目根目录运行。

## 示例参数
- 自激活：`a=0.05, b=3.5, K=1, n=4, gamma=1`。
- 互抑制：`alpha=3, n=3`。
- Repressilator：`alpha=20, n=3, gamma=1`。
- 随机出生--死亡：平均分子数为 `2, 8, 17` 的泊松分布。

代码只生成已解释的演示模型，并不拟合真实实验数据。论文参考文献的 DOI 可在 LaTeX 末尾查阅。
