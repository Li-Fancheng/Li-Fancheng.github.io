# 最小基因调控回路：可复现学习笔记

正文按六章组织：反应与调控建模；双稳态、开关与记忆；两节点回路及 81 种符号拓扑；振荡、时间筛选与适应；分子涨落与随机切换；真实网络中的有效反馈与模块耦合。关键推导集中讲解，每章仅保留少量 section。全文使用 `ctexrep`，各章从新页开始。

## 源码组织

- `main.tex`：编译入口，通过 `\include` 整合六章、附录和参考文献。
- `preamble.tex`：公共宏包、字体、页眉、章节与图表编号。
- `frontmatter.tex`：标题、摘要与目录。
- `chapters/*.tex`：各章独立源码，包含推导与 TikZ 示意图。
- `main.pdf`：编译结果。
- `figures/`：数值图、逐图拓扑索引与预览图。
- `code/topology_inventory.json`：81 种拓扑的边符号、编号和结构分组。
- `original/`：历史稿件；本轮合并前的完整源码与 PDF 保存在 `original/before_consolidation/`。

## 编译与复现

```bash
python -m pip install -r requirements.txt
bash build.sh
```

需要 XeLaTeX、ctex 和 TikZ；中文使用 TeX Live 自带的 Fandol 字体。`build.sh` 重新生成数值图并编译三遍。仅修改文字时，也可在项目根目录对 `main.tex` 执行 XeLaTeX 三遍。

## 绘图与数学复核

- `code/make_figures.py`：自激活、互抑、三节点负反馈、前馈适应与出生--死亡分布。
- `code/topology_analysis.py`：81 种带标签图、45 种节点交换类别、八组分类及逐图索引。
- `code/extended_examples.py`：两节点恢复/振荡、缓冲积分/比例前馈/泄漏反例。
- `code/positive_feedback_oscillation.py`：本文 R8 模型的快慢分支、迟滞跳跃及周期调节。
- `code/bistability_details.py`：双稳态分支、吸引域相线与势函数；复核整个 n=3 互抑族的不对称稳态及稳定性，以及三节点环的第一 Lyapunov 系数。

数值代码用于检查解析代入和展示机制，不拟合实验数据。81 种拓扑的分类基于固定边符号、有界非负产生率、一阶降解、无延迟的模型；含正回路的 53 种是多稳态候选，R8 的 10 种是 Hopf 符号候选，均不代表所有参数下实现相应功能。
