# 基因调控笔记

西湖大学 2026 年秋季《定量生物学导论》课程学习笔记。

- [最小基因调控回路的理论基础](main.md)：从反应规则到一、二、三组分回路，包含完整推导和拓扑图谱。
- [基因调控网络的理论](GRN_theory.md)：反馈、噪声诱导切换、布尔网络与集体响应。

正文保留六章完整推导、81 种两节点拓扑图谱和参考文献。公式使用 `$…$` 与 `$$…$$`，建议在支持数学公式的 Markdown 阅读器中打开。图片均使用相对路径；移动或分享时请将 `main.md` 与 `figures/` 一起保留。

## 内容导航

1. 从反应到调控模型：质量作用律、产生与降解、启动子结合和有效调控。
2. 一个变量：自反馈、双稳态、吸引域、势函数、迟滞与记忆。
3. 两节点回路：稳定性、互抑开关、81 种符号拓扑及 R8 快慢反馈。
4. 三个组分：负反馈振荡、时间筛选、前馈适应与积分反馈。
5. 分子数较少时：主方程、泊松稳态、涨落与随机记忆寿命。
6. 从最小回路到真实网络：lac 系统、组合调控与模块耦合。
7. 附录：81 种两节点拓扑逐图索引。
8. 参考文献与延伸阅读。

## 文件组织

- `main.md`：最小回路笔记，含图片、公式与内部跳转。
- `GRN_theory.md`：网络、随机表达与集体行为笔记。
- `figures/*.png`：数值图、回路示意图和三张拓扑图谱。
- `code/`：数值计算、数学复核和绘图脚本。

- `original/`：原有历史存档，保持原样；不参与当前 Markdown 的阅读与生成。

正文以 Markdown 保存，回路示意图为 PNG。阅读和复现数值图无需安装 TeX。

## 复现数值图与数学检查

```bash
python3 -m pip install -r requirements.txt
bash build.sh
```

`build.sh` 运行以下脚本，更新 PNG 数值图、拓扑图谱及枚举数据：

- `code/make_figures.py`：自激活、互抑、三节点负反馈、前馈适应与出生–死亡分布。
- `code/topology_analysis.py`：81 种带标签图、45 种节点交换类别、八组分类及三张拓扑图谱。
- `code/extended_examples.py`：两节点恢复与振荡、缓冲积分、比例前馈及泄漏反例。
- `code/positive_feedback_oscillation.py`：R8 模型的快慢分支、迟滞跳跃与周期调节。
- `code/bistability_details.py`：双稳态分支、吸引域与势函数；复核整个 n=3 互抑族的稳态及稳定性，以及三节点环的第一 Lyapunov 系数。

数值脚本不重建已转换的七张静态回路示意图，这些图片直接保存在 `figures/` 中。

数值代码用于检查解析代入和展示机制，不拟合实验数据。81 种拓扑的分类基于固定边符号、有界非负产生率、一阶降解、无延迟的模型。含正回路的 53 种是多稳态候选，R8 的 10 种是 Hopf 符号候选，均不代表所有参数下都实现相应功能。
