- [从单细胞分裂差异到群体增长](single_cell_to_population_growth/cell_cycle_correlations_note.md)
- [基因调控网络的理论](grn/GRN_theory.md)

四个主题各分为 3 篇，共 12 篇。每篇围绕一个完整问题，从模型的起点讲到结果的解释和检验；多数篇目的技术推导与补充问题归在篇末，可按需要展开。趋化的三篇依次讨论单细胞输运、浓度感知与精度限制、信号反馈和集体聚集，其中感知篇的推导直接随正文展开。

上面的链接是各主题的源文件目录；编号为 `01_`、`02_` 等的 Markdown 文件是各篇正文，图片仍与源文件放在同一主题目录。原有科学内容完整保留，沿用原有章节、公式和图号。2026 年 10 月的文字补充围绕具体的生长、刺激和测量情景，说明模型为什么这样建立、结果怎样理解，以及哪些实验可以区分不同解释；公式保持不变。

网站阅读入口为 `/notes/qbio_course/`，各主题原网址保留为阅读目录，并兼容指向旧章节的锚点链接。阅读顺序与目录摘要记录在 `data/qbio_series.json` 中。趋化的复现命令见其 README。

自制图共用 [plot_style.py](plot_style.py)：文字使用 Arial（缺少时回退到可用的无衬线字体），公式使用 Computer Modern，导出保留字形轮廓的 SVG 与 300 dpi PNG。网页优先使用 SVG，图片可点击查看原图。自制图与论文图的展示宽度逐张记录于仓库的 `data/qbio_figures.json`，按信息密度调整；论文原图文件保持不变。
