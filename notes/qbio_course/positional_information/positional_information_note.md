# 基因表达如何编码空间位置
## 从 Bicoid 梯度和 French flag model 到位置解码与网络优化

细胞核接触的是分子，却需要在合适的位置作出表达选择。第一篇从梯度的形成讲到有噪声的表达边界；第二篇讨论多个基因怎样共同定位，以及局部精度为何不等于全局可辨认；第三篇再问，哪些分子网络能够产生可靠的位置图案。

各篇沿用原有章节、公式和图号。补充推导可按需要展开，跨篇引用可直接跳转。

1. [从浓度梯度到可靠的表达边界](01_gradient.md) — 沿着 Bicoid 的产生、扩散、基因调控与分子读取，解释空间边界怎样形成，又为何会波动。
2. [多个基因怎样共同确定位置](02_joint_decoding.md) — 把联合表达看作位置读数，连接噪声几何、Fisher 信息、位置后验与全局互信息。
3. [怎样的调控网络能产生可靠的位置图案](03_network_optimization.md) — 从信息最大化的表达曲线出发，加入反应动力学、分子资源与下游读取，比较模型预测和发育实验。
