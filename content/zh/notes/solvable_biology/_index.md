怎样从一个无法完整求解的生物系统里，提取出一个值得求解、可以求解，而且解答仍有生物意义的问题？

这里把八个案例写成问题重构实验。开头先只使用现象和有限的测量事实，暂不借用论文已经选好的模型：选一个明确的观测量，实际计算一种朴素解释，看它保留了什么、删掉了什么，再决定下一步需要哪些变量。数学工具在有效规律显出结构以后才接上来。

重点是三次不同的压缩。**问题的压缩**把“解释整个细胞”改成“解释出生偏差怎样跨代恢复”；**自由度的压缩**从全部反应中选出当前出生大小；**结构的识别**则在未知映射线性化后认出可分析的随机递推。前两步决定算出的东西是否还回答原问题，第三步才让已有工具发挥作用。

## 八次实验，各练一种重构操作

| 案例 | 先计算哪种朴素尝试？ | 需要学会的选择 |
| --- | --- | --- |
| [细胞大小控制](/notes/solvable_biology/cell_size/) | 无大小反馈的定时倍增会怎样积累误差？ | 从事件间的未知映射，反推恢复需要的斜率，再让具体规则竞争 |
| [转录爆发](/notes/solvable_biology/transcription_bursts/) | 恒定产生和线性降解允许多宽的计数分布？ | 用分布约束隐藏状态，同时主动寻找静态等价的另一机制 |
| [布朗棘轮](/notes/solvable_biology/brownian_ratchet/) | 始终接触的刚体增加反应率后能否前进？ | 从几何门控识别随机通道，依据限速环节选择消元方式 |
| [组织刚性](/notes/solvable_biology/tissue_rigidity/) | 只有面积代价的铺砌抵抗剪切吗？ | 从“是否移动”改问“构型间是否存在低能路径” |
| [胚胎位置编码](/notes/solvable_biology/positional_information/) | 直接反解平均表达曲线能唯一给出坐标吗？ | 把识别问题转成由读数分布定义的统计任务 |
| [最优采食](/notes/solvable_biology/foraging/) | 只最大化单次收益会不会产生离开时间？ | 先定义长期比较目标，再检查当前状态是否足以预测未来 |
| [种群扩张](/notes/solvable_biology/range_expansion/) | 从全局池独立抽样会自然产生大片扇区吗？ | 由活动区域寻找有效自由度，再检验边界描述有无漏掉记忆 |
| [中性生态](/notes/solvable_biology/neutral_ecology/) | 区域库的独立抽样已经能生成多少稀有物种？ | 检查何时可交换个体的替代能够闭合成计数过程 |

## 怎样判断一次简化已经够用？

可以先读[细胞大小控制](/notes/solvable_biology/cell_size/)：我们尚未知道 Sizer 或 Adder，就能从未知映射求恢复条件，再决定应测条件斜率、残差和谱系相关。它展示了怎样用可解性反过来约束机制，而不必先选中机制。

再读[种群扩张](/notes/solvable_biology/range_expansion/)与[组织刚性](/notes/solvable_biology/tissue_rigidity/)。前者检查冻结内部和压缩边界是否仍保留未来的来源，后者检查能垒是否回答了所选力学问题。一个模型可以足以解释粗化或几何阻碍，却仍不足以预测全部微观运动。

其余案例从分布、等待、识别与决策出发，分别检验状态、时间尺度和目标。朴素模型并不必须被宣布错误：独立抽样有时已经解释了某些统计；这时需要指出什么额外测量才能要求增加机制。改变模型应由明确的预测缺口推动。

每篇末尾才设置“论文究竟多做了什么？”，比较哪些实验选择了有效描述、哪些推导只是教学构造。这里不把合理的重构伪装成作者真实的发现历史，也不把可以计算的结果自动当成唯一的生物机制。
